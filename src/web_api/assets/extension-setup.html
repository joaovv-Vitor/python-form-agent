VozForm no Chrome

A aplicação web continua disponível. A extensão usa este mesmo servidor para preencher a aba que você escolher.

  1. Compile a extensão com npm run build:extension na pasta frontend.
  2. Abra chrome://extensions, ative o Modo do desenvolvedor e escolha Carregar sem compactação.
  3. Selecione a pasta extension/dist deste projeto.
  4. Abra o site com o formulário e clique no ícone VozForm para abrir o painel lateral.
  5. Escolha Usar formulário desta aba. A conexão com o servidor local é automática.
  6. Na primeira gravação, use Ativar microfone e permita o acesso na tela do Chrome.

Não é necessário copiar códigos. O servidor reconhece a identidade da extensão VozForm. Mantenha o servidor Python ligado durante o uso.

Ao migrar da versão 0.1, remova a extensão antiga e carregue novamente extension/dist. A nova versão usa uma identidade fixa para reconhecer o servidor automaticamente.

Se o servidor estiver ocupado, encerre a sessão web anterior. O envio é feito por você no site, após conferir os valores.
